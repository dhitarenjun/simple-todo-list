# Simple To-Do List

Simple To-Do List adalah aplikasi web sederhana untuk membantu pengguna mengelola tugas harian.

## Fitur

- Menambahkan tugas
- Menandai tugas sebagai selesai
- Mengedit tugas
- Menghapus tugas
- Memfilter tugas berdasarkan status

## Teknologi

- HTML
- CSS
- JavaScript

## Pengujian

Program dibuat untuk tugas Software Testing dan digunakan untuk melakukan pengujian serta menemukan defect pada aplikasi.

## Struktur File

- `index.html` — halaman utama aplikasi
- `style.css` — mengatur tampilan aplikasi
- `script.js` — mengatur fungsi aplikasi
